3) OPTION A — RUN ON JACK'S MACHINE (LOCAL)
--------------------------------------------------------------------------------
  ONE-TIME / EACH DAY — connect Worker:

  Windows:
    1. Login as JackTest
    2. If banner says "Worker not connected", click Windows (.bat)
    3. Double-click the downloaded UTS-Connect-*.bat
    4. Keep that black window OPEN
    5. Refresh UTS page → green pill "Worker · <PC-name>"

  Mac:
    1. Login as JackTest
    2. Click Mac (.sh)
    3. In Terminal:
         chmod +x ~/Downloads/UTS-Connect-*.sh
         ~/Downloads/UTS-Connect-*.sh
    4. Keep Terminal open
    5. Refresh UTS → green Worker pill

  THEN RUN:
    1. Open your project
    2. Select "My PC (local)"
    3. Click "Scan application"  (or Generate / Run)
    4. Watch browser open on YOUR PC
    5. Use Stop to cancel if needed

  LOCAL CHECKLIST
    [ ] Logged in as JackTest
    [ ] Worker window open + green Worker pill
    [ ] My PC (local) selected
    [ ] Chrome or Edge installed
    [ ] App URL reachable from your PC (VPN if required)

  Stop                 = Cancel job and close browser

--------------------------------------------------------------------------------
7) COMMON PROBLEMS
--------------------------------------------------------------------------------
  Worker not connected
    → Download connector, run it, keep window open, refresh page

  Browser opens on server, not my PC
    → You chose Server — switch to My PC (local)

  Job stuck / browser frozen
    → Click Stop, then retry

  Mac script will not run
    → chmod +x then run the .sh again

  Windows blocks .bat
    → More info → Run anyway
