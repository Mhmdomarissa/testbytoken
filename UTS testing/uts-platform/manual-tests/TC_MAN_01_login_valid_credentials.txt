================================================================================
TEST CASE: TC_MAN_01 - Login with Valid Credentials
Type: MANUAL | Priority: High | Module: Authentication
================================================================================

Objective:
Verify that a registered user can log in to SMART BANK with valid credentials
and reach the home/dashboard screen.

Preconditions:
- SMART BANK application is installed and reachable
- Test user account exists (admin_user / Pass@123)
- User is on the Login screen

Test Data:
  username: admin_user
  password: Pass@123

--------------------------------------------------------------------------------
Steps  Action                          Expected Result
--------------------------------------------------------------------------------
1       Launch SMART BANK app           Login screen is displayed with
                                        Username and Password fields

2       Enter username: admin_user      Username field shows entered value

3       Enter password: Pass@123          Password field masks the input

4       Click Login button                User is authenticated and redirected
                                        to home/dashboard screen

5       Verify welcome/dashboard          Account summary or menu is visible;
                                        no error message shown

--------------------------------------------------------------------------------
Expected Result:
User logs in successfully and lands on the home screen without errors.

Postconditions:
User session is active. Log out after test if required.
