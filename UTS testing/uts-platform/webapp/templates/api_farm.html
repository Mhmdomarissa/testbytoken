How to use (step by step)

Follow these steps the first time. A sample GET URL is already filled — try it now.

  1. Send a simple request

    In Request builder, keep Method GET and the sample URL, then click Send request. Check Live response for status and body.

  2. Save the test

    Click Save to collection. It appears under Saved API tests.

  3. (Optional) Set parameters

    In Parameters, add JSON like {"baseUrl":"https://api.example.com"}, click Save parameters. Use {{'{{baseUrl}}'}}/login in the URL field.

  4. (Optional) Login + token chain (EscuelaJS example)

    Click Load Login sample below — Method POST, Expected status 201 (not 200), extractors [{"name":"token","path":"access_token","source":"json"}]. Send → Save. Then Load Profile sample (Bearer {{'{{token}}'}}) and Send again.

  5. Run the suite

    Put Login at the top (use ↑ ↓). Click Run all saved APIs, then Open last report.

  6. (Optional) Import

    Use Import OpenAPI / Postman to load many APIs from a JSON file, then run them.

Tip: Built-in values you can type anywhere — {{'{{timestamp}}'}}, {{'{{date}}'}}, {{'{{uuid}}'}}, {{'{{token}}'}} (after extract).
