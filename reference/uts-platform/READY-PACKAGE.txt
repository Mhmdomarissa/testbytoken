INSTALL ON SERVER (one time)
--------------------------------------------------------------------------------
1. Copy this ZIP to the server and extract, e.g.:
     C:\UTS\UTS-Test-Automation-Suite

2. Install Python 3.10+ (Add to PATH) and Google Chrome

3. Double-click SETUP.bat
   (or RESET-ADMIN.bat if login was broken before)

4. Confirm .env has:
     UTS_ADMIN_USERNAME=admin
     UTS_ADMIN_PASSWORD=admin
     UTS_SYNC_ADMIN_PASSWORD=true
     UTS_SIMPLE_PASSWORDS=true
     UTS_HOST=0.0.0.0
     UTS_PORT=5050
     UTS_PUBLIC_URL=http://144.91.113.113:5050

5. Allow firewall TCP 5050

6. Double-click RUN-WEB.bat  (keep window open)

7. Open: http://144.91.113.113:5050/login
